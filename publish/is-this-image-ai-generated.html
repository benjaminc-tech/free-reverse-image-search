Is this image AI generated?

Sometimes the file tells you. Some AI tools embed Content Credentials (C2PA) that say the image was AI generated, and this free tool reads that record. When there is no record, nothing in the file can prove the image is real, and no free tool can reliably detect AI images from pixels alone.

Steps

  1. Get the most original copy you can. A file downloaded from where it was first posted keeps more data than a screenshot or a reshare.
  2. Open the free tool and drop the image in. Everything is read in your browser.
  3. Look at the Content Credentials line. If the file carries a record, it shows what the record states, such as that the image was AI generated, and which tool made it.
  4. Check the metadata table. A Software field means the file was saved by an editor or app, so it is not an untouched camera original.
  5. Reverse search it. Finding the image on an AI art gallery, or an older version with different details, often answers the question faster than any file check.

What it can't tell you

  • It does not detect AI images. It reads what the file declares about itself, nothing more.
  • No Content Credentials does not mean genuine. Most images carry no record, most AI tools do not add one, and Instagram, WhatsApp and X strip the record on upload.
  • It reads the record but does not verify the cryptographic signature, so treat it as what the file claims, not proof.

Questions

What are Content Credentials (C2PA)?

A signed record some tools embed in an image that describes how it was made. Tools like ChatGPT, DALL-E and Adobe can add one. When present, it can state that the image was AI generated.

Can any free tool tell for sure if an image is AI?

No tool can tell for sure from the pixels alone, and detectors that claim to give a percentage can be wrong in both directions. Provenance records and finding the original source are more reliable.

Why does a screenshot show no credentials?

A screenshot is a new image made by your phone or computer, so it carries none of the original file's records. Use the original file when you can.

Is the image uploaded to check it?

No. The Content Credentials and metadata are read inside your browser, and the file never leaves your device unless you choose to send it to a search engine.
