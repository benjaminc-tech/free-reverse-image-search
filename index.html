Perceptual hashes

A perceptual hash is a short fingerprint of what an image looks like, unlike a checksum which changes completely if a single byte changes. Compare two images by counting differing bits (the Hamming distance): under about 5 usually means the same image, over about 15 usually means a different one.

Measured on this build: resizing, heavy JPEG recompression, brightness shifts and converting to grayscale all leave pHash completely unchanged, and trimming 5% off each edge moves it by 2 bits. Rotation defeats it, though: turning an image 90 degrees shifts pHash by 24 bits, which reads as a different image. Rotate it back before comparing.

Free, and staying that way

There is no paid tier, no pro version, no trial that expires, and nothing to renew. You do not need an account and you are never asked for an email. Improvements land here the next time you load the page, at no cost, because there is no other version to sell you.

It costs nothing to run, which is why it can stay free: the whole tool is one HTML file that does its work in your browser. There is no server holding your images, so there is no bill that would eventually have to be passed on to you.

What is measured. This page counts visits and which buttons get used, so it is possible to tell whether any of it is useful. Your images are not part of that: no file, no filename, no image address, and no EXIF values ever leave your browser. Session recording is off and the address bar is stripped of its query before anything is sent, because the address can contain the very image you are searching for.

How this works. Reverse image search engines need to be able to fetch the image themselves, so a URL can be handed straight to all four. A file on your own device has no public address, and rather than upload it somewhere, this hands it to you: share it into another app on a phone, or copy it and paste it into an engine on a desktop. Everything else, the EXIF parsing and the hashing, is computed here in the page. Nothing you load is sent anywhere.
