    Perceptual hashes

    A perceptual hash is a short fingerprint of what an image looks like, unlike a checksum which changes completely if a single byte changes. Compare two images by counting differing bits (the Hamming distance): under about 5 usually means the same image, over about 15 usually means a different one.

    Measured on this build: resizing, heavy JPEG recompression, brightness shifts and converting to grayscale all leave pHash completely unchanged, and trimming 5% off each edge moves it by 2 bits. Rotation defeats it, though: turning an image 90 degrees shifts pHash by 24 bits, which reads as a different image. Rotate it back before comparing.

    How it works

    Why does it hand the image back to me instead of searching directly?

    Search engines have to be able to fetch the image themselves, so a URL can be passed straight to all four. A file on your own device has no public address. Rather than upload it somewhere to give it one, this hands it back to you: share it into another app on a phone, or copy and paste it into an engine on a desktop.

    Which app do I share into on a phone?

    The Google app, the one with the colored G. The share sheet lists Chrome and Google side by side and only Google runs Lens, so picking Chrome is the common mistake.

    Is anything really not uploaded?

    Nothing you load is sent anywhere. The EXIF parsing, the Content Credentials reading and the hashing all happen in this page. The whole tool is one HTML file, so you can read it yourself and confirm there is no upload path, which is not something a hosted tool can offer you.

    What is measured, then?

    Visits and which buttons get used, so it is possible to tell whether any of this is useful. Your images are not part of that: no file, no filename, no image address and no EXIF values ever leave your browser. Session recording is off, and the address bar is stripped of its query before anything is sent, because the address can contain the very image you are searching for.

    Will it stay free?

    Yes. There is no paid tier, no pro version, no trial that expires and nothing to renew. You are never asked for an email. It costs almost nothing to run, because there is no server holding your images, so there is no bill that would eventually have to reach you. Improvements land here the next time you load the page.
